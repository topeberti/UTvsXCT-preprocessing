01 — Motivation
02

Voids don’t show up to the eye — but they change how sound moves through the laminate.

The problem with ground truth

X-ray CT gives a true, voxel-level void volumetric fraction (VVF) — but it’s slow, lab-bound, and not something you run on a production floor.

The opportunity in ultrasound

Pulse-echo UT is fast and already used for inspection. Attenuation is the classic feature linking an A-scan to internal quality — no CT scanner required.

This tutorial: build that attenuation feature, pixel by pixel, from a raw UT volume.

02 — Physics
03

Why attenuation tracks void content

Voids scatter sound instead of reflecting it cleanly → less energy returns → a smaller backwall echo. The attenuation formula turns “how much smaller” into a comparable dB number.

03 — Pipeline
04

Seven steps, one image per sample

Steps 4 & 5 (red) are the two judgment calls in the whole pipeline — everything else is deterministic signal processing.

Pipeline — Step 1 / 7

1
Load the volume, align the frontwall
cscan.ipynb
volume = io.load_tif(original_path)
# reshape so every A-scan is one row
volume = volume.reshape((nx*ny, 1, -1))
volume = signal.align_signals_optimized(
    volume, point=100)
Before → after alignment

Why: gates are defined by fixed sample indices. If the frontwall peak lands somewhere different for every A-scan — probe tilt, surface height variation, couplant thickness — a fixed gate window stops measuring the same physical depth from pixel to pixel. Aligning every A-scan so its frontwall peak sits at the same index (here, sample 100) makes the gates comparable everywhere in the scan.

Alignment uses the same Hilbert-envelope peak detection as Step 2 — it just runs first, on the raw signal, to find where the frontwall echo is.

Pipeline — Step 2 / 7
06
2
Amplitude envelope (Hilbert transform)
signal.py — envelope()
volume = volume.astype(np.int16)
volume = volume - volume.mean()
# analytic signal via Hilbert transform
z = hilbert(volume, axis=axis)
envelope = np.abs(z)
Raw RF signal vs. its envelope

Why: the RF signal oscillates around zero — its instantaneous value depends on phase, not just how much energy came back. Taking the absolute value of the Hilbert transform gives one smooth, always-positive curve tracing the true peak amplitude, so gate measurements stay stable regardless of phase.

Every downstream step — alignment, masking, gating, attenuation — operates on this envelope, never the raw RF trace.

Pipeline — Step 3 / 7
07
3
Separate material from background
cscan.ipynb
# material = signals with a real echo
ids = np.where(envelope.max(axis=0) > 40)
material = envelope[:, ids[0], ids[1]]
mean_signal = material.mean(axis=1)
Scan grid — material vs. background

Why: not every scan position is on the part — edges, fixtures, and pure water/air path return almost no echo. Filtering by peak envelope amplitude (here, > 40) keeps only signals that actually bounced off material, and their average defines a clean reference waveform for choosing gate positions.

Pipeline — Step 4 / 7
08
4
Choosing the two gates
cscan.ipynb
gate1 = (70, 180, 80)  # frontwall check
gate2 = (270, 400, 2)  # target echo
signal.plot_gate(mean_signal, gate1)
Mean material signal, gates highlighted

Why: gate 1 checks the front surface actually coupled well — a high threshold (80) means a weak front echo marks the whole signal unreliable (result: NaN, not zero). Gate 2 brackets the echo you actually care about; its peak (A2) is the amplitude that gets converted into an attenuation value.

These two windows are the only hand-tuned parameters in the whole pipeline — and they change with probe, material, and thickness.

Pipeline — Step 5 / 7
09
5
The attenuation formula
20 · log10 ( reference / A2 )
reference

A fixed calibration amplitude chosen once per dataset (here, 20) so dB values stay comparable across samples.

A2

The peak envelope amplitude found inside gate 2 — the target echo, per pixel.

dB scale

Larger dB → smaller A2 → more attenuated → more likely to contain voids or scatterers.

invalid pixels

If A1 or A2 falls below its gate threshold, the pixel is marked NaN — not zero.

signal.py — attenuation()
A1 = segment1[segment1 >= threshold1].max()  # or 0
A2 = segment2[segment2 >= threshold2].max()  # or 0
value = 20 * np.log10(reference / A2) if A1 > 0 and A2 > 0 else np.nan

04 — Practical Notes
12

Four things that will bite you

01
Gates are dataset-specific

Retune gate1/gate2 whenever probe, material, or laminate thickness changes — they don’t transfer between setups.

02
The envelope discards phase

You gain amplitude robustness for gating, but lose polarity information a raw RF-based method could use.

03
Reference is a convention

Not a physical law — pick one value and keep it fixed per dataset so dB values stay comparable across samples.

04
NaN, not zero

Thresholded gates return NaN for invalid pixels — don’t let them silently collapse to zero/black downstream.

Where this fits the VVF prediction pipeline

06 — Summary
14

Takeaways

Attenuation drops where sound scatters off voids — that’s the physical link this whole pipeline exploits.
Align every A-scan’s frontwall peak first, so gates measure the same depth everywhere.
Work on the Hilbert envelope, not raw RF — peak amplitude, not phase, is what gating needs.
Two hand-tuned gates do all the real work: a validity check (gate 1) and a target echo (gate 2).
20·log10(reference/A2), computed per pixel, is the entire attenuation C-scan.
Bake every hyperparameter into the output filename — reproducibility isn’t optional in a research pipeline.
